# Memory Game

A fun and interactive memory card game that challenges players to match pairs of cards. This project supports English and Japanese localization and is deployed live on [Netlify](https://memory-game-proj.netlify.app/).

## Live Demo
[Play the game here!](https://memory-game-proj.netlify.app/)

---

## Features
- **Localization**: Supports both English and Japanese languages with a toggle option.
- **Dynamic Gameplay**: Choose emoji categories and the number of cards.
- **Accessible Design**: Screen reader-friendly and keyboard accessible.
- **Responsive UI**: Optimized for desktop and mobile devices.

---

## Technologies Used
- **Frontend**: React.js
- **CSS**: Custom styling with transitions and animations.
- **Localization**: Language state management for English and Japanese.
- **Deployment**: Hosted on Netlify.

---

## Installation

To run the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/memory-game.git
   cd memory-game
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

---

## How to Play
1. Select your preferred language using the dropdown menu.
2. Customize the game by choosing a category and the number of cards.
3. Match all pairs of cards as quickly as possible!
4. Once all pairs are matched, a "Game Over" screen will appear.
